    ⚙️ How It Works

    1. You set the 10 academic and lifestyle details of a student (sliders or exact values).
    2. JavaScript validates the values and sends them to the Flask API (POST /api/predict).
    3. Flask re-validates everything and feeds the feature vector to the trained Decision Tree.
    4. The tree walks its learned decision rules and returns the predicted class — Poor, Average, Good or Excellent — plus the probability of every class.
    5. The page shows the prediction, animates a confidence bar from 0% to the model's confidence, explains the key driving factors, and saves the result to your browser's local history.
